# Roadmap

## Near term

- Configure optional SonarCloud repository variables and token if analysis is desired.
- Complete native-library redistribution review before enabling public desktop release workflows.
- Run the bundle smoke test on real Windows, macOS and Linux runners and fix any packaging gaps.

## Features

- Built-in video downloader.
- Disc image (ISO/CSO) and optical-disc tools.
- OCR for scanned PDFs and layout-preserving PDF/DOCX conversion.
- Native screen recorder and media player.
- Windows code signing and macOS notarization.

## Quality

- Compare the General Add Files, Output Settings, Clip, Mux and Options dialogs against the intended design.
- Integration tests against more FFmpeg builds and hardware encoders.
- Raise branch coverage above 80%.
